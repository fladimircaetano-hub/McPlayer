Exclusão de aparelhos

Abra o aparelho por MAC + código na aba Acesso / Auditoria e use "Excluir". Listas e clientes são preservados.

Cada aparelho é excluído individualmente, com o código digitado de novo para confirmar. A data de entrada e o WhatsApp do cliente dependem do 005_access_reset.sql, que deve ser rodado uma vez no SQL Editor do Supabase.

dashboard/sql/001_schema.sql -> estrutura base (apps, aparelhos, listas, clientes, auditoria) dashboard/sql/005_access_reset.sql -> data de entrada + telefone do cliente dashboard/sql/002_cleanup.sql -> apaga as tabelas legadas (opcional, com backup) dashboard/sql/003_admin.sql -> confere/adiciona administradores dashboard/sql/004_rollback.sql -> volta atrás (somente antes do 002)
